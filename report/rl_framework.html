📌 Big Picture — 5 thành phần RL

Setting RL: Contextual Bandit (1-step MDP). Mỗi VN request là một episode hoàn chỉnh — agent quan sát state, chọn composite action, nhận reward terminal. Không có state transition giữa nhiều step trong cùng episode (về mặt MDP).

1 Môi trường (Environment)

Môi trường gồm 4 thành phần phối hợp với nhau:

Đặc tính của Environment

Stochastic ở khâu sinh state

  • VN topology + demand random
  • Substrate load fractional_drop U[0, 0.7] mỗi episode
  • Đây là nguồn nhiễu chính qua các batch

Deterministic ở khâu commit

  • Một khi mapping được chốt, cost xác định
  • shortest_path deterministic (Dijkstra)
  • Reward = f(mapping, substrate) cố định

2 Tác nhân (Agent — PolicyNetwork)

Là một neural network với 4 heads chia sẻ chung 1 GCN encoder.

HeadInputOutputMục đích
GCN Encoder (X, A_norm) per domain snode embeddings (n_s, 32) Encode substrate topology + tài nguyên
node_head vnode_feat ⊕ substrate_ctx logits (n_v,) Rank vnodes (thứ tự embed)
link_head vlink_feat ⊕ substrate_ctx logits (n_e,) Rank vlinks (thứ tự allocate BW)
cand_head vnode_feat, snode_embeds, cpu_slack scores per (v, s) Chấm điểm snode cho mỗi vnode (attention)
value_head 🆕 mean_pool(ctx) ⊕ mean_pool(vnode_feats) scalar V(s) Critic baseline cho Actor-Critic

File chính: algorithms/rl_oa_mp_vne_v2/policy_network.py

Patches áp dụng (V2 final):
  • cand_head scores được normalize: /5 - mean → clamp[-10, 10] để tránh softmax saturation
  • Soft mask -1e4 thay -inf cho infeasible candidates
  • Max-pool thay mean-pool ở state representation (preserve dominant signal)
  • Gumbel-Max sampling thay Categorical.sample (equivalent ở τ=1, vectorizable cho Top-K)

3.2 Micro state — evolve trong autoregressive decoding

Trong rank_direct, sau mỗi vnode được pick một snode, state cập nhật:

$s_t = (s_0,\ \underbrace{\text{used\_snode\_ids}_t}_{\text{collision mask}},\ \underbrace{v_t}_{\text{vnode hiện tại}})$

used_snode_ids tích lũy sau mỗi bước → cand distribution bị mask khác → policy thấy different "allowed actions".

4 Hành động (Action)

Action là composite — gồm 3 thành phần được sample tuần tự:

ComponentPhân phốiAction space sizeSampling method
Vnode permutation σ_v Plackett-Luce trên node_scores n_v! Gumbel-Top-K (vectorized)
Vlink permutation σ_e Plackett-Luce trên link_scores n_e! Gumbel-Top-K
Snode mapping {σ(v_i)} Categorical autoregressive với collision mask ∏ (n_s − i) Gumbel-Max + mask used
Composite action: $a = \big(\sigma_v,\ \sigma_e,\ [s_1, s_2, \ldots, s_{n_v}]\big)$

Snippet sampling cand (V2 cost-min)

for v in ordered_vnodes:
    i = orig_idx[v.id]
    scores_i = cand_scores[i].clone()

    # Collision mask: snodes already used → -inf
    if used_snode_ids:
        mask_vals = [-inf if pool_i[j].id in used_snode_ids else 0.0
                     for j in range(len(pool_i))]
        scores_i = scores_i + mask_vals

    # Gumbel-Max sample (equivalent to Categorical.sample at τ=1)
    pos = self._gumbel_argmax(scores_i)

    # log_prob and entropy still analytical via Categorical
    dist = torch.distributions.Categorical(logits=scores_i)
    cand_lp.append(dist.log_prob(pos))
    cand_ent.append(dist.entropy())

    chosen_snode = pool_i[int(pos.item())]
    mapping[v.id] = chosen_snode.id
    used_snode_ids.add(chosen_snode.id)

5 Reward (V2 — Cost Minimization)

Trước đây V2 dùng R/C ratio. V2 hiện tại đổi sang cost minimization:

Success (mapping commit thành công):

$$r = -\frac{\text{cost}}{\text{scale}},\quad \text{scale} = 1000$$

Trong đó:

$$\text{cost} = \underbrace{\sum_{v} \text{cpu\_demand}(v) \cdot \text{cpu\_price}(\sigma(v))}_{\text{node cost}} + \underbrace{\sum_{e} \text{bw}(e) \cdot |\text{path}(e)|}_{\text{link cost (single-path)}}$$

Fail:

$$r = -10.0 \quad \text{(clearly worse than worst success)}$$

So sánh đổi objective

AspectR/C (cũ)Cost-min (V2 hiện tại)
Công thức successrevenue / cost-cost / 1000
Range[0, ~1][-5, ~0]
Fail penalty-1.0-10.0
VN-normalized?Yes (revenue trừ size)No (cost ∝ size)
adv_std trong train0.061.0 (×16)
Eval mean cost14801422 (-3.9%)
Quan trọng: reward terminal — tính 1 lần ở cuối episode (sau khi commit). Không có intermediate reward giữa các vnode picks. Đây là đặc tính của contextual bandit.

Đây không phải multi-step MDP kinh điển. Phân biệt:

Note: Autoregressive cand decoding bên trong 1 episode có tạo "micro MDP" với state evolution. Nhưng đứng từ góc nhìn REINFORCE update (terminal reward, no γ), ta xem composite action như 1 big step.

7. Training Loop

Pseudo-code chính

for episode in 5000:
    # 1. Environment reset
    env.reset()              # substrate += fractional load drop
    vn = generate_random_vn()

    # 2. Agent forward — produce composite action a
    ordered_vnodes, ordered_links, mapping, log_probs, entropies, value = \
        agent.rank_direct(vn, sample=True)
    #   - sample σ_v via Gumbel-Top-K on node_head
    #   - sample σ_e via Gumbel-Top-K on link_head
    #   - autoregressive: sample s_i via Gumbel-Max on cand_head[v_i],
    #     mask used_snode_ids before each pick

    # 3. Environment step — commit mapping + compute reward
    reward = try_embedding_direct(vn, ordered_links, mapping)
    #   - single-path commit
    #   - reward = -cost/1000 if success else -10

    # 4. Store transition + periodic Actor-Critic update
    trainer.record(log_probs, value, entropies, reward)

    if (episode + 1) % batch_size == 0:
        trainer.update()
        #   advantage = R - V(s).detach()   per-instance baseline
        #   advantage = (adv - mean) / std   normalization
        #   policy_loss = -mean(log_prob * adv)   per-head normalized
        #   critic_loss = MSE(V(s), R)
        #   entropy_bonus = -β(t) * H(π)   annealing β
        #   total = policy_loss + 0.5*critic_loss - β*entropy
        #   AdamW + cosine LR + grad clip 5.0

📋 Tóm tắt 1 đoạn cho giảng viên

Mô hình của em là Contextual Bandit (single-step MDP) với:

  • Môi trường: SubstrateNetwork (mạng vật lý multi-domain) + VN generator (sinh request) + Commit engine (single-path V2 mới) + Cost function (Σ cpu·price + Σ bw·hop).
  • Tác nhân: PolicyNetwork với 5 components: GCN encoder + 4 heads (node, link, cand, value). Tổng ~80k tham số.
  • State: macro = (G_s, VN, cpu_slacks) — quan sát một lần đầu episode. Micro = (s₀, used_snode_ids, current_vnode) — evolve trong autoregressive decoding.
  • Action: composite a = (σ_v, σ_e, [s₁...s_n]) — permutation vnodes/vlinks + 1 snode/vnode (collision-masked).
  • Reward: cost minimization — r = -cost/1000 (success), -10 (fail). Terminal, không γ.
  • Học: Actor-Critic với V(s) baseline. Critic loss MSE = (R − V(s))². Entropy regularization annealing.
